# AGENTS.md

This repo holds two separate products. Work inside the one you were asked about.

- `livevision/`: HUD overlay, autoclip, LiveVision iOS companion, OBS cloud VM.
  Contract for agents: [`livevision/AGENTS.md`](livevision/AGENTS.md).
- `lingualens/`: language coach server, courses, iOS and Android apps.
  Start with [`lingualens/README.md`](lingualens/README.md); tests: `.venv/bin/python tests/smoke.py`.

Run each product's commands from inside its folder: imports, configs and
scripts are relative to it.
